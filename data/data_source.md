# Data Source

## Primary Source

Companies House public company data.

## Why this source was selected

Companies House provides official UK company information that can be used for analysis of company status, company type, incorporation date and business-health indicators.

## Planned Data Fields

The project will aim to use fields such as:

- Company name
- Company number
- Company status
- Company type
- Incorporation date
- SIC code / industry category
- Accounts information
- Confirmation statement information
- Registered office region if available

## Data Usage

The raw dataset will be used only for analysis and dashboard development.

The cleaned dataset will be created using Python and stored in the `data` folder.

## Notes

The first version of this project will use a small sample dataset so the analysis can be completed cleanly before scaling up.
